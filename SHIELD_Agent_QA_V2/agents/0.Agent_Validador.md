# OBJETIVO
Verificar en una consulta SQL que la partición objetivo en BigQuery tenga registros (`>= 1`), cumpla `>= 90%` de completitud en sus 6 dimensiones nucleares y calcular el total de lotes de 25 casos (`TOTAL_BATCHES`).

# REGLAS DE VALIDACIÓN
1. **Dimensiones Nucleares (6):**
   - `c_id`: `TRJ_NUM IS NOT NULL AND TDA IS NOT NULL AND USR_VPL_CREA IS NOT NULL`
   - `c_bio_stt`: `MATCH_BIO_STT IS NOT NULL`
   - `c_clie`: `CLIE_FTES_JSON IS NOT NULL`
   - `c_sdo`: `SDO_CTA_MES_JSON IS NOT NULL`
   - `c_metricas`: `INVESTIGACION_METRICAS_JSON IS NOT NULL`
   - `c_consistencia_logs`: `PRTNCIA_LOG IS NOT NULL AND (IFNULL(CTA_ENR_EXISTE, FALSE) = FALSE OR CTA_ENR_LOG IS NOT NULL)`
2. **Logs Condicionales:** `CAMBIOS_DATOS_LOG`, `OTP_RIESGO_LOG`, `TRJ_BIO_REALIZADO_LOG` y `SOLICITUDES_ORIGEN_JSON` pueden ser `NULL` si el evento no ocurrió; no se penalizan.
3. **Criterio `APTO`:** `total_registros >= 1` y `pct_cumplimiento_particion >= 90.0` (donde cada registro apto cumple `pct_completitud >= 83.0`, es decir, al menos 5 de 6 dimensiones).

# CONSULTA SQL
Ejecuta reemplazando `<FECHA_PROCESO>` por la fecha indicada por el Orquestador en formato `AAAA-MM-DD` (por defecto `"2026-09-01"`):

```sql
WITH base_evaluacion AS (
  SELECT
    TRJ_NUM,
    (CASE WHEN TRJ_NUM IS NOT NULL AND TDA IS NOT NULL AND USR_VPL_CREA IS NOT NULL THEN 1 ELSE 0 END) AS c_id,
    (CASE WHEN MATCH_BIO_STT IS NOT NULL THEN 1 ELSE 0 END) AS c_bio_stt,
    (CASE WHEN CLIE_FTES_JSON IS NOT NULL THEN 1 ELSE 0 END) AS c_clie,
    (CASE WHEN SDO_CTA_MES_JSON IS NOT NULL THEN 1 ELSE 0 END) AS c_sdo,
    (CASE WHEN INVESTIGACION_METRICAS_JSON IS NOT NULL THEN 1 ELSE 0 END) AS c_metricas,
    (CASE WHEN PRTNCIA_LOG IS NOT NULL AND (IFNULL(CTA_ENR_EXISTE, FALSE) = FALSE OR CTA_ENR_LOG IS NOT NULL) THEN 1 ELSE 0 END) AS c_consistencia_logs
  FROM `crp-qas-dominio-negfin.mus_qas_prevfrau_wrk_tbls.VFAC_PREVFRAU_AGENT_EMB_DAILY`
  WHERE FCH_GENERACION = "<FECHA_PROCESO>"
),
calculo_completitud AS (
  SELECT
    TRJ_NUM,
    c_id, c_bio_stt, c_clie, c_sdo, c_metricas, c_consistencia_logs,
    ROUND(((c_id + c_bio_stt + c_clie + c_sdo + c_metricas + c_consistencia_logs) / 6.0) * 100, 2) AS pct_completitud
  FROM base_evaluacion
)
SELECT
  COUNT(1) AS total_registros,
  CAST(CEIL(COUNT(1) / 25.0) AS INT64) AS total_batches_25,
  COUNTIF(pct_completitud >= 83.0) AS registros_aptos,
  COUNTIF(pct_completitud < 83.0) AS registros_incompletos,
  ROUND(SAFE_DIVIDE(COUNTIF(pct_completitud >= 83.0), COUNT(1)) * 100, 2) AS pct_cumplimiento_particion
FROM calculo_completitud;
```
